## 🚀 Deployment Instructions

### Deploy to Vercel
1. Install Vercel CLI (`npm i -g vercel`) or push the code to a GitHub repository.
2. In the Vercel Dashboard, import the repository.
3. Keep default settings (Framework Preset: **Other**) and click **Deploy**.

### Deploy to GitHub Pages
1. Push this project to your GitHub repository:
   ```bash
   git add .
   git commit -m "UR-WORLD-AQUARIUM - Complete Premium Pet & Aquatic Lifestyle Website"
   git push origin main
   ```
2. In repository settings &rarr; **Pages**, select branch `main` / root `/` and click **Save**.
